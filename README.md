## 📖 About

A collection of small exercises that explore the **Node.js runtime**
from the inside: the module system, `fs`, `os`, `process`, `timers`
and a bit of `app.js` glue code.

## ✨ Features

- `fs`, `os`, `process`, `timers` deep dives
- Each topic isolated in its own file
- No dependencies — pure Node
